# web/ : 화면

## 이 폴더가 하는 일

로그인, 채팅, 승인함, 리콜 알림, 관리자 화면. 확정된 프론트엔드 기술 스택은 Vite + React + Tailwind CSS이며, 프론트엔드 빌드 결과물은 FastAPI가 제공한다. 채팅·승인함 API(D6 오전)가 나온 뒤 붙인다.

현재 로그인 화면은 HTML·CSS·JavaScript로 먼저 구현·검증한 MVP 상태다. React + Tailwind CSS 전환과 Vite 빌드 결과물의 FastAPI 제공은 아직 진행하지 않았다.

- 주인: 강경희
- 입력: API 응답
- 출력: 화면
