# web/ : 화면

## 이 폴더가 하는 일

로그인, 채팅, 승인함, 리콜 알림, 관리자 화면. 확정된 프론트엔드 기술 스택은 Vite + React + Tailwind CSS이며, 프론트엔드 빌드 결과물은 FastAPI가 제공한다. 채팅·승인함·내 정보·관리자 사용자 관리 화면은 실제 API에 연결되어 있다(아래 작업 기록 11-07~11-09). `login.html`·`login.js`·`login.css`는 처음 만든 정적 로그인 화면이며, React 빌드(`web/react-app/dist`)가 없을 때 `backend/main.py:388-395`이 대신 내준다.

기존 MVP 상태: 로그인 화면은 HTML·CSS·JavaScript로 먼저 구현·검증했다. 당시 React + Tailwind CSS 전환과 Vite 빌드 결과물의 FastAPI 제공은 아직 진행하지 않았다.

현재 D6 상태: React 채팅 프론트의 채팅 API adapter, SSE 파싱·오류 처리, threads 매핑, 승인 대기 UI, Memory adapter를 구현했다. 11-07 시점에는 React 테스트 44개 통과와 production build 성공까지 확인했고 실제 API 통합 검증은 미완료였다. 이후 `GET /threads/{id}` 대화 불러오기(11-09), 승인함 `GET /approvals`·`POST /approvals/{id}` 연결(11-09), 기억 초기화 DELETE(11-08)가 붙었고, 작업 기록 최신 값은 vitest 205개 통과·build 성공(11-09, 박진형 행)이다. 브라우저에서 처음부터 끝까지 실제 사용자 흐름을 확인한 기록은 이 파일에 없다.

- 주인: 강경희
- 입력: API 응답
- 출력: 화면
