# 현직자 설문 응답 요약 (2026-11-13 배포, 11/15 회신 마감)

설문 문항은 [questionnaire_2026-11-13.md](./questionnaire_2026-11-13.md)에 있다. 이 요약은 `docs/PRD.md` 2장과 4장에 적은 사실만 옮긴 것이며, 이름·회사명·연락처는 설문에서 묻지 않았다.

## 표본

- 응답자: 현직 개발자 1명. 가이드 p.14의 외부 시선(외부 검토자)으로 이 응답을 썼다.
- 편의 표본이며 기억에 의존한 자기 보고라 대표성이 없다. 응답이 1명이라 비율 대신 "1명 중 1명"으로 적는다.

## 응답 내용

| 항목 | 응답 |
|---|---|
| 2주 동안 규정·절차를 몰라 다른 사람에게 물은 횟수 | 1~2회(주 0.75회로 환산) |
| 2주 동안 규정·절차 질문을 받은 횟수 | 3~5회(주 2회로 환산) |
| 질문 한 건의 해결 시간 | 10분 미만~30분 |
| 2주 동안 규정을 찾거나 묻는 데 쓴 시간 | 0.25~0.75시간 |
| 자주 묻는 주제 | 3개 중 2개(경비·법인카드, 구매·결재선)가 이 서비스가 다루는 주제 |
| 받은 답에 근거 문서가 함께 오는 경우 | "거의 없음"(1명 중 1명) |
| 근거를 붙여 답하는 도구 사용 의향 | "써 보겠다" |
| 도구에서 가장 중요한 것 | 정확한 근거, 쓰던 메신저에서 바로 사용 |
| 이런 도구의 결정·결재 부서 | 해당 현업 부서장, 경영진 |

## 읽는 법

- 질문 빈도와 지불 주체는 1명의 응답이라 계속 가설로 둔다(`docs/PRD.md` 2장, 4장 한계).
- 정책이 바뀌는 빈도의 실측과 공개 MR의 질문 신호는 `docs/PRD.md` 2장과 4-4절에 따로 있다.
