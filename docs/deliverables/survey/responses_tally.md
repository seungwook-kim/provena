# 현직자 설문 문항별 응답 집계 (응답 4명)

회신된 응답 원본을 문항 원문과 함께 문항별·선택지별 응답 수로 옮긴 문서다. 이 파일만으로 문항과 응답을 함께 읽을 수 있다. 배포한 설문지 원문은 [questionnaire_2026-11-13.md](./questionnaire_2026-11-13.md), 해석과 환산은 [responses_summary.md](./responses_summary.md), 집계 기준은 [aggregation_method.md](./aggregation_method.md)에 있다.

> [!NOTE]
> 응답은 익명으로 받았고 설문지에서 개별 응답을 공개하지 않는다고 안내했으므로 응답자별 행은 나열하지 않는다. 아래 선택지별 응답 수가 회신된 응답 내용 전체다.

| 항목 | 내용 |
|---|---|
| 설문 기간 | 1차 배포 2026-11-13(회신 기한 11/15), 2차 배포 2026-11-16(회신 기한 11/17 12시). 문항은 두 배포가 같다 |
| 회신 방식 | 설문지 파일에 고른 번호를 적어 회신하거나, 문항 번호와 고른 번호를 텍스트로 회신 |
| 응답 수 | n=4 (1차 배포분 1명, 2차 배포분 3명) |
| 익명 여부 | 익명. 이름·회사명·연락처는 묻지 않았다 |
| 개별 응답 | 응답자별 행과 문항 사이의 응답 연결은 적지 않는다 |

## 세는 법

- 모든 선택지를 적고, 아무도 고르지 않은 선택지는 0명으로 적는다.
- 복수 선택 문항과, 단일 선택 문항에서 한 사람이 두 선택지를 함께 고른 경우는 고른 선택지마다 1명씩 셌다. 이런 문항은 선택 수 합계를 따로 적는다.
- 응답이 10명 미만이라 비율 대신 명 수로 적는다.
- 4명 모두 모든 문항(D5 자유 의견 제외)에 답했다.
