# evals/ : 평가

## 이 폴더가 하는 일

평가셋 v1(30건, D2 동결)·v2(50건 이상, D5 동결)는 템플릿 자리(`dataset_v1.jsonl`, `freeze.py`, `FROZEN.json`)를 따른다. 바꾸기 전에 `PREREGISTER.md`에 기대를 먼저 적는다. 동결한 평가셋은 고치지 않는다.

- 주인: 공동 (평가셋), 하위 폴더는 각 주인
- 입력: 평가셋, 그래프
- 출력: 지표, `results/`
