# evals/latency/ : 응답 시간 측정 도구

## 이 폴더가 하는 일

응답 시간과 단계별 시간을 재고 다시 계산하는 도구를 둔다. `deploy_latency.py`는 배포된 서비스에 평가셋 v2 50건을 문항마다 새 대화로 `POST /chat`에 보내 첫 토큰·전체 시간을 잰다. `deploy_citation_gold.py`는 그 행의 인용 청크를 정답 위치와 맞추고(LLM 호출 없음), `deploy_ragas.py`는 같은 결과를 RAGAS 4지표로 채점한다(사전 등록 62.25). `stage_times.py`는 배포 Langfuse 트레이스에서 단계별 시간을 다시 계산하고, `run_local_pg.py`·`local_summary.py`·`local_stages.py`는 로컬 Postgres로 돌린 측정 결과를 묶고 단계별로 센다(사전 등록 62.8, 62.10). 결과 파일은 `evals/results/` 아래에 둔다.

- 주인: 김승욱
- 입력: 배포 주소, 평가셋 v2, 측정 결과 폴더(`rows.jsonl`)
- 출력: 시간·비용 표, 인용 정답 대조, 단계별 시간 (결과는 `EVAL_REPORT.md` 8장)
