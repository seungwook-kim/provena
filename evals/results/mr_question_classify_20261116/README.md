# 공개 MR 물음표 댓글의 질문·정책 질문 분류 (2026-11-16)

- 날짜: 2026-11-16
- 기준 커밋: origin/main `eb8c9aac`
- 대상: `docs/PRD.md` 4-4 문단의 집계(`evals/results/market_evidence_20261113/`, 2026-10 병합 MR 322건, 물음표 댓글 310개, 정책 경로 MR 11건의 24개)
- 비용: 0원. GitLab 공개 웹 엔드포인트 읽기만(`/-/merge_requests/<iid>/discussions.json`, 호출 간격 1.2초, 일반 User-Agent). LLM 호출 없음.

## 분류한 사람

**분류는 AI 모델(Claude Opus)이 아래 규칙으로 했다.** 사람의 두 번째 확인은 아직 하지 않았고, `classification.csv`의 `사람확인_질문인가`, `사람확인_정책절차질문인가`, `사람확인자` 칸을 비워 두었다. 사람이 확인해 값이 달라지면 그 칸에 적고 아래 집계를 다시 센다.

## 입력과 재현

1. `t2_fetch.py`: 커밋된 `mr_question_rows.json`에서 물음표 댓글이 있던 MR 118건의 사람 댓글을 다시 읽는다. 집계 규칙은 원래 스크립트(`count_mr_questions.ps1`)와 같다(시스템 댓글과 자동 계정 제외, ``` 코드 블록과 주소를 뺀 본문에 `\?(\s|$)`). 원래 집계 시각(2026-11-13 04:38 UTC 무렵) 뒤에 달린 댓글은 뺀다. 다시 읽은 결과 물음표 댓글 310개, 정책 경로 24개로 원래 집계와 같다. 계정 이름은 저장하지 않았고 원문 전체 파일은 커밋하지 않는다.
2. `t2_sample.py`: 정책 경로 MR의 물음표 댓글 24개 전부와, 정책 경로가 아닌 물음표 댓글 286개에서 무작위 30개를 고른다. 시드는 **20261116**이고 `(MR iid, 댓글 id)` 순으로 정렬한 목록에서 `random.Random(20261116).sample(…, 30)`로 뽑는다. 결과 `selected.json`(멘션, 주소, 코드 블록을 가린 본문).
3. `t2_classify.py`: 아래 규칙의 분류를 `classification.csv`, `classification.md`, `summary.json`으로 쓴다.

## 분류 규칙

- **질문인가 = 예**: 상대에게 정보(사실, 이유, 의도, 해석, 진행 상태)나 판단(결정, 의견)을 답으로 구하는 문장이 있다. **아니오**: 물음표가 리뷰·승인·머지·파이프라인 실행·충돌 해결 같은 작업 요청, "~할까요?" 꼴의 수정 제안, 인사, 다른 사람 질문의 인용(답변 댓글)에만 붙었다.
- **정책·절차 질문인가 = 예**: 질문인가가 예이고, 핸드북의 규정·업무 절차가 무엇을 요구하는지, 누가 책임지는지, 요건의 적용 범위·강도가 어디까지인지, 그런 절차가 있는지를 묻는다. **아니오**: 기술 구현, 제품 설계, 문서 서식·배치, MR 진행 상태를 묻는다.
