# 합동 검토 Supervisor 팀 선택 1회 측정 (2026-11-17)

체크포인트 3조 게이트 주의 G4("정책 질문 멀티가 단일과 차이 0.000, 멀티에이전트 최소형 판정")에 대해, 합동 검토 Supervisor가 요청마다 돌릴 팀을 고르게 한 스위치 `REVIEW_TEAM_SELECT`(`backend/graph/departments/review.py`, 코드 기본 꺼짐)를 켜고 1회 잰 기록이다.

**결론: 정답 쟁점 누락률이 0.649로 기존 운영 기준 0.577보다 나빠졌다. 서비스 설정에서는 이 스위치를 끈 채로 둔다(`backend/graph/service_profile.py`의 `SERVICE_ENV`에 넣지 않음). 런당 비용은 0.00273달러로 줄었다.**

## 조건

- 측정 시각: 2026-11-17 09:54:10 ~ 09:55:16 KST. 사전 등록 행(62.82)은 측정 전에 작성했다(2026-11-17 09:53, `evals/PREREGISTER.md` 반영 예정). 팀 선택 규칙 문구(`backend/graph/departments/teams.py`의 `TEAM_SELECT_RULE`)는 측정 전에 정했고 측정 뒤 고치지 않았다.
- 평가셋: `evals/dataset_review_v1_gold.jsonl`(조원 2명 확인 정답, sha256 `9b235976eff5…`), 10문항 x 1회. 되물을 문항 2개(8, 9번)는 정답 쟁점 지표에서 빠지고, 정답 쟁점은 8문항 37개다.
- 실행: `run_team_select.py`(이 폴더). `evals/agent/exp_review_v1.py`의 team 갈래 함수(`make_arm`, `run_arms`, `compute_review_metrics`, `match_gold`)를 그대로 쓰고 single 갈래는 돌리지 않았다. 서비스 설정 61.51을 채운 뒤 `REVIEW_TEAM_SELECT=1`.
- 검색: 측정기 기본 MemoryStore(색인 스냅샷). 운영 DB는 읽지도 쓰지도 않았다. 모델: Anthropic API Haiku 5.5. 누적 비용 상한 0.25달러.
- 원시 결과: `team/rows.jsonl`(문항별 쟁점 행, 팀 상태, 검색 기록), `summary.json`(지표), `per_item.json`(아래 표의 원자료, `per_item.py`로 0원 계산), `run.log`(실행 출력).
