# 승인 대기 시스템 몫 측정 (로컬, Postgres 체크포인터)

결과 파일: `approval_latency_postgres.json`(Postgres), `approval_latency_memory.json`(메모리 체크포인터 기준선). 이 문서는 json의 숫자를 그대로 옮겨 설명한 것이다.

## 무엇을, 왜 쟀나

승인 대기는 사람이 결정을 기다리는 시간이 대부분이라 사람 몫이다. 그 시간은 재지 않고, **기계가 쓴 시간**(멈추면서 체크포인트를 저장하는 시간, 멈춘 자리를 읽는 시간, 재개해서 끝나는 시간)만 쟀다. 배포와 같은 종류인 Postgres 체크포인터에서 값이 얼마나 느는지 보려고 메모리 체크포인터와 같은 도구로 나란히 쟀다. 가이드 D8 단계별 시간의 "승인 대기" 칸을 채우기 위해서다(`EVAL_REPORT.md` 8장 "승인 대기").

## 어떻게 쟀나

- 환경: **로컬**. 같은 PC의 Docker 컨테이너 Postgres 16.15, 빈 시험용 DB. 운영 DB·운영 서비스에는 접속하지 않았다.
- 모델: 가짜 모델·가짜 검색기(팀 시험의 `tests/decision_fixtures.py`, `tests/team_review_fakes.py`). LLM 호출 0회, 네트워크 없음(HTTP 항목은 TestClient).
- 횟수: 그래프·체크포인터 조합마다 n=20회, p50·p95·max를 저장.
- 버전: 코드 `e8b8059`, Python 3.14.7, langgraph 1.2.19, langgraph-checkpoint-postgres 3.2.0, psycopg 3.3.6(json의 `measured_with`).
- 단위: 아래 표는 밀리초(json은 초).

## 숫자 (n=20, p50 / p95, 밀리초)

| 그래프 | 체크포인터 | 멈춤 | 대기 확인 | 재개 첫 노드까지 | 재개부터 끝 |
|---|---|---|---|---|---|
| 결정표 변환 | Postgres | 263.0 / 277.9 | 4.9 / 6.2 | 8.8 / 10.3 | 29.6 / 33.7 |
| 결정표 변환 | 메모리 | 208.8 / 245.6 | 0.8 / 1.2 | 3.1 / 10.1 | 4.3 / 11.3 |
| 합동 검토 | Postgres | 94.2 / 120.0 | 3.9 / 4.7 | 7.6 / 10.6 | 55.3 / 80.2 |
| 합동 검토 | 메모리 | 27.2 / 37.7 | 0.7 / 1.1 | 3.3 / 5.5 | 5.1 / 6.9 |

승인 없는 질문 그래프 한 번(전체 시간): 체크포인터 없음 15.0 / 18.6, 메모리 20.8 / 23.2, Postgres 133.9 / 159.7. 결정표 변환을 실제 라우터로 부른 왕복(TestClient, Postgres): 변환 요청 285.1 / 362.7, 승인 결정 요청 87.6 / 110.2. 이 둘은 json에만 있고 `EVAL_REPORT.md`에는 옮기지 않았다.

**`EVAL_REPORT.md` 8장과 대조.** 8장 "승인 대기(시스템 몫)" 문단과 표의 Postgres·메모리 값(결정표 변환 멈춤 263.0·재개부터 끝 29.6, 합동 검토 94.2·55.3, 메모리 4.3·5.1 등)은 이 json에서 다시 계산한 값과 모두 같았다(소수 첫째 자리 반올림).

## 읽는 법

- 체크포인트 저장·읽기 몫은 대기 확인에서 약 3~4밀리초, 재개부터 끝에서 결정표 변환 약 25밀리초, 합동 검토 약 50밀리초다(Postgres 값에서 메모리 값을 뺌).
- 멈춤 값은 첫 호출 준비 시간이 섞여 있어 메모리 쪽도 크다(결정표 변환 208.8). 8장에 적은 이전 메모리 측정(3.9밀리초)과 다른 이유는 8장 문단을 따른다.

## 한계

- 가짜 모델이라 LLM 시간은 들어 있지 않다(LLM 시간은 `stage_report_final_api.md` 몫).
- **로컬 한 대, 한 번의 실행**이다. 운영(Cloud Run과 Supabase) 값이 아니며 네트워크 지연이 없다. 운영 승인 대기 시간은 이 문서의 값으로 말할 수 없다.
- n=20이라 p95는 큰 값 하나에 흔들릴 수 있다.
- 사람이 기다린 시간은 정의상 재지 않았다.
