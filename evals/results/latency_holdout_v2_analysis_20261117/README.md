# 검증 v2 답을 낸 문항의 응답 시간 분석 (2026-11-17, 0원)

체크포인트 4-1("새 검증 20건의 답을 낸 질문 p95가 3회 모두 10초를 넘습니다") 대응을 위한 원인 분석이다. 새 측정이나 LLM 호출 없이 저장된 결과 파일만 다시 계산했다(비용 0원). 분석 뒤 후보 A를 코드 기본 꺼짐(빈 값)으로 구현했고, 유료 재측정 전 사전 등록은 `PREREGISTER_split_vote_wait.md`에 있다.

## 자료와 방법

- 측정: `evals/results/deploy_latency_holdout_v2_provena-api-00172-rex/`(검증 v2 20건 x 3회, 리비전 `provena-api-00172-rex`, 커밋 `194dfd9a`). 답을 낸 문항은 회차마다 14건, 3회 42행이다.
- 단계 시간: 같은 폴더의 `stage_times_nodes.json`(Langfuse 트레이스에서 낸 노드별 시간, `evals/latency/stage_times.py` 방식)과 `run*/rows.jsonl`의 `cost_by_step`(단계별 호출 수·토큰·호출 시간 합), `path.judge_votes`(근거 충분 판정 다수결의 표 구성과 표마다 도착 시각).
- 운영 판 `provena-api-00181-zub`(커밋 `9bc7d587`)의 검증 v2 측정은 아직 없다. 두 커밋 사이에 판정·다수결·LLM 설정 코드(`backend/graph/build.py`, `backend/graph/answer_fixes.py`, `backend/services/llm.py`, `backend/graph/service_profile.py`)의 차이는 없다(`git diff --stat 194dfd9a 9bc7d587 -- backend/`).
- p95는 가장 가까운 순위다. 답을 낸 문항이 14건이면 p95는 회차 최댓값과 같다.
- 질문 내용이나 평가셋의 기대 답은 보지 않았다. 문항 번호, 결과 종류, 시간, 토큰, 표 구성만 썼다.

- 판정은 같은 호출 3개를 동시에 보내고 같은 결론 2표가 모이면 확정한다(`build.py` `voted`, `answer_fixes.votes_settled`). 첫 두 표가 갈리면 셋째 표를 끝까지 기다린다. 기다림 상한은 첫 두 표가 모두 "근거 없음"일 때만 있다(`GRAPH_NONE_VOTE_WAIT_S`=1.0, 사전 등록 62.72).
- 505는 3회 모두 첫 두 표가 충분과 일부로 갈려 셋째 표까지 기다렸다.
- 판정 호출 시간은 출력 토큰 수에 비례한다. 답을 낸 42행에서 호출당 출력 토큰과 호출당 시간의 상관계수는 0.996이고, 100토큰당 약 0.5초다. 42행의 호출당 출력 토큰 중앙값은 658, 505는 1,051~1,403이다. 판정은 추론 수준 low로 돌고(`LLM_EFFORT_BY_TASK`) 출력 형식의 구절은 이미 80자 이내로 제한되어 있어, 출력의 많은 몫은 추론 토큰으로 보인다. 기록에 추론 토큰 수가 따로 없어 이 몫은 추정이다.

## 7. 권고

- A를 먼저 넣고 측정한다. 코드가 작고, 저장 기록에서 결론이 바뀌는 판정이 0/6이며, 1·2회차의 초과를 줄인다.
- 구현: 환경 변수 `GRAPH_SPLIT_VOTE_WAIT_S`(코드 기본 빈 값 = 지금 동작). `backend/graph/build.py`(`voted`, `two_split`, `vote_log`의 `split_capped`), `backend/graph/answer_fixes.py`(`split_vote_wait_s`), 시험 `tests/test_split_vote_wait.py`. 근거 없음 표가 섞인 갈림은 대상이 아니다(결정 0100의 재검색·거절 경로 그대로).
- A만으로는 3회차처럼 세 표가 모두 늦게(7.5~9.6초) 오는 경우가 남아, 3회 모두 10초 아래를 보장하지 못한다. 남는 몫은 판정 출력 길이(B 또는 E)이고, 둘 다 판정 결론을 바꿀 수 있어 측정 없이 넣지 않는다.
- 측정 계획: A를 적용한 트래픽 0% 판에서 검증 v2 20건 3회와 v2 50건 1회를 잰다(00172 기준 요청당 0.0072달러, 약 0.43달러 + 0.25달러). 판정 표 구성(`judge_votes`의 `how`)과 최종 판정, 인용 지표, 답을 낸 문항 p95를 00172-rex·00181-zub와 비교한다.
