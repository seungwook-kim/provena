# 배포 점검 화면 출력 (provena-api-00029-qbd, 2026-11-09 22:3x KST)

결과 JSON 저장은 폴더가 없어 실패했고(FileNotFoundError), 아래는 실행 창에 출력된 표를 그대로 옮긴 것이다. JSON은 재실행으로 다시 만든다.

| 번호 | 점검 | 결과 | 근거 |
|---|---|---|---|
| L0 | 두 계정으로 로그인한다 | 통과 | A와 B의 user_id가 다름 |
| U1 | 로그인하지 않은 요청은 401이다 | 통과 | 7개 경로 모두 401 |
| X1 | 사용자 B는 A의 대화를 읽지 못한다(404) | 통과 | B의 조회 404(not_found), B의 목록에 없음 |
| X2 | B의 기억 조회에 A의 기억이 섞이지 않는다 | 통과 | B의 조회 3가지 모두 B 자신의 기억만 나옴(표식 대조) |
| R1 | 관리자 전용 경로는 일반 사용자에게 403이다 | 통과 | 3개 경로 모두 403 |
| E1 | 오류 본문에 스택 트레이스와 입력값이 없다 | 통과 | 5가지 오류 응답 모두 깨끗함 |
| H1 | 응답에 X-Content-Type-Options와 X-Frame-Options가 있다 | 통과 | 4개 응답 모두 있음 |
