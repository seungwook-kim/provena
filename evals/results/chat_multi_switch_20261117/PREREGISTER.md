# 사전 등록 메모: /chat 멀티 그래프 전환 뒤 유료 재측정 (2026-11-17, 측정 전 작성)

이 메모는 `evals/PREREGISTER.md` 본문과 별도로, `/chat`을 Supervisor 멀티 그래프(`QUESTION_GRAPH_MODE=multi`)로 바꾼 운영 판을 재측정하기 전에 기대값과 멈춤 규칙을 적어 둔 것이다. 본문 번호는 본문을 고치는 쪽에서 붙인다. 본표 번호는 62.90이다(`evals/PREREGISTER.md`, 같은 판에서 함께 재는 갈린 판정 대기 상한은 62.89).

## 무엇을 재나

- 대상: 멀티 그래프 전환과 판정 대기 지연 수정(`GRAPH_SPLIT_VOTE_WAIT_S`)을 함께 담은 운영 판. 트래픽 0%로 배포한 판에 측정 계정으로 직접 보낸다.
- 평가셋과 횟수: 동결 v2 50건 3회, holdout_v2 20건 3회. 측정 도구와 지표 정의는 직전 운영 측정과 같다.
- 비교 기준: 직전 운영 판(단일 그래프)의 같은 평가셋·같은 도구 측정값. 같은 날 측정한 단일 판 값이 있으면 그것을 쓴다.

## 기대값 (측정 전)

멀티 그래프는 단일 그래프의 노드와 분기 함수를 그대로 꺼내 쓰고, 코드 라우팅은 LLM 호출을 더하지 않는다(`PARITY.md`). 그래서 답 경로는 단일과 같고 차이는 모델 응답의 회차 간 흔들림 범위 안이라고 본다. 로컬 1회 비교(`evals/results/single_vs_multi_g4_v2_9bc7d587/`)에서는 인용 정확도 단일 0.960 대 멀티 0.940, 오답 근거 0.040 대 0.080, 50건 중 46건이 같은 결과였다.

| 지표 | 기대 범위(직전 단일 판 대비) |
|---|---|
| 인용 정확도(3회 평균) | 단일 값 ±0.03 안 |
| 오답 근거(3회 평균) | 단일 값 +0.04 이하(더 나빠지는 폭) |
| p95 응답 시간 | 단일 값 +1.0초 이하 |
| 과잉 거절, 올바른 거절, 환각 위험 | 단일과 같은 수준(문항 단위 변화는 기록만) |

## 멈춤 규칙

- 첫 회(v2 50건 1회)에서 오류 행이 1건이라도 나오거나, 인용 정확도가 단일 값보다 0.06 넘게 낮거나, 오답 근거가 단일 값보다 0.08 넘게 높으면 나머지 회차를 돌리지 않고 멈춘다. 원인을 찾아 고친 뒤 다시 등록한다.
- 3회를 마친 뒤 위 기대 범위를 하나라도 벗어나면 트래픽을 올리지 않고 결과를 보고한다. 되돌리기는 환경 변수 `QUESTION_GRAPH_MODE=single`(또는 `off`)이다.
- 기대 범위 안이면 결과를 보고한 뒤 트래픽 전환을 진행하고, 공식 수치를 멀티 경로 값으로 옮긴다.

## 기록할 것

- 회차별 원시 결과, 문항별 결과 종류와 인용, done의 `refuse_stage`·`path`, 단계별 비용(`cost_by_step`), 응답 시간.
- 문항당 LLM 호출 수(단일과 같아야 한다. 늘었으면 원인을 적는다).
- 이 메모의 설정(서비스 설정 61.51 + `QUESTION_GRAPH_MODE=multi`)을 측정 중에 바꾸지 않는다. 측정 뒤 설정을 바꾸면 새로 등록한다.
