## 확인 항목

- R1: 재시작 뒤에도 대기 건이 승인함 목록에 있다
- R2: 체크포인트에서 내용이 복원된다(쟁점표 행 수, 초안 행 수가 준비 때와 같다)
- R3: 대기 중인 대화에 새 질문을 보내면 409 approval_pending(쟁점표 건, LLM 호출 전에 막힘)
- R4: 일반 계정(B)이 결정을 보내면 403
- R5: 관리자 결정 200, 상태 approved 또는 rejected
- R6: 결과: 쟁점표 승인은 저장 문구와 같은 행 수, 반려는 저장 0, 결정표 승인은 승인된 표 목록에 행 수 > 0(반려는 승인된 표 0)
- R7: 같은 결정 재요청 200(같은 상태), 반대 결정 409
- R8: 재요청 뒤 결과가 바뀌거나 늘지 않음(대화 답 글·개수, 같은 업무 종류의 승인된 표 수)
- R9: 결정 뒤 승인함 대기 목록에서 빠짐
- R10: 재개 기록(GET /approvals/{id}): resume_count 1, duplicate_ignored_count 1, last_resume_result duplicate_ignored(db/112 운영 적용 때만 판정)
