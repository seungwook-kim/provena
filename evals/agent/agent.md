# evals/agent/ : 에이전트 평가

## 이 폴더가 하는 일

질문 그래프 지표(인용 정확도, 거절, 판 날짜 표시 등), LLM 채점, 단일 대 멀티 비교, 결정표·리콜 평가. 개선 전후 2회 이상 잰다(G5).

- 주인: 김승욱
- 입력: 평가셋, 그래프
- 출력: 지표, 비교표
