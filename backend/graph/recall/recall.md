# backend/graph/recall/ : 답변 리콜 (F-02)

## 이 폴더가 하는 일

바뀐 섹션을 인용한 예전 답을 찾아 결론이 바뀌었는지 판정하고, 받은 사람과 업무시스템(웹훅)에 알린다. 판정 실패는 "확인 필요"로 알린다.

- 주인: 김승욱
- 입력: 바뀐 섹션 목록(`ChangedArticle`)
- 출력: 리콜 알림(`RecallNotice`), 함께 볼 정책 후보
