# backend/graph/ : LangGraph 질문 처리 그래프

## 이 폴더가 하는 일

질문 분류, 재작성, 재검색, 답 작성, 인용 검사, 답변 저장. 상태(`state.py`)와 조립(`build.py`)을 둔다. 단일 그래프(D4)로 기준 점수를 재고 Supervisor 구조(D5)로 다시 잰다(G4).

- 주인: 김승욱
- 입력: 질문, 검색 결과
- 출력: 인용이 붙은 답, 이벤트(`events.py`)
