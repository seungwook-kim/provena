# backend/memory/ : 사용자별 장기 기억

## 이 폴더가 하는 일

Store namespace에 사용자 id를 넣어 사용자 사이에 기억이 섞이지 않게 한다. 팀·역할·담당 서비스를 기억한다. State(이번 대화)와 Store(대화를 넘어 남길 것)를 나눈다(G4).

- 주인: 김승욱
- 입력: 사용자 id, 프로필
- 출력: 기억 조회·저장
