# backend/rag/ : RAG: 수집과 검색

## 이 폴더가 하는 일

수집·파싱·청킹·적재(`ingest/`)와 임베딩·검색·리랭킹(`retrieve/`)을 둔다. 인덱스를 만들 때마다 `data/manifest.jsonl`에 문서와 청크 목록을 남긴다(G3).

- 주인: 박진형
- 입력: GitLab 핸드북 git 저장소
- 출력: 청크, 검색 결과(`backend/schemas/chunk.py`)
